「うちは使いすぎだろうか」と考えるとき、比べる相手がないと判断できません。総務省が毎月行っている家計調査には、全国の平均が費目ごとに載っています。まずはその数字を確かめるところから始めます。

## 二人以上の世帯の平均は月30万243円

2024年の家計調査によると、二人以上の世帯の消費支出は1か月あたり **300,243円** でした。平均世帯人員は2.88人です。

| 費目 | 1か月あたりの平均 |
|---|---|
| 食料 | 85,040円 |
| 住居 | 18,074円 |
| 光熱・水道 | 23,110円 |
| 家具・家事用品 | 12,615円 |
| 被服及び履物 | 9,609円 |
| 保健医療 | 15,276円 |
| 交通・通信 | 41,588円 |
| 教育 | 11,703円 |
| 教養娯楽 | 29,098円 |
| その他の消費支出 | 54,132円 |
| **消費支出（合計）** | **300,243円** |

いちばん大きいのは食料で、支出全体の約28%を占めます。次いで「その他の消費支出」（こづかい、交際費、たばこなど）が約18%、交通・通信が約14%と続きます。

## 平均と比べるときの3つの注意点

### 1. 世帯人数がそろっていないと比べられない

この数字は「二人以上の世帯」の平均で、平均世帯人員は2.88人です。夫婦2人の世帯と、子ども2人がいる4人世帯では食費も教育費も違います。単身世帯の平均は別に集計されているので、一人暮らしの方はこの表の数字とは比べられません。

### 2. 「住居」が安く見えるのは持ち家が含まれるため

住居費の平均が18,074円と、家賃の相場より大幅に低く見えます。これは持ち家の世帯が多く含まれているためです。持ち家の場合、住居費として計上されるのは修繕費などで、住宅ローンの返済は消費支出に含まれません（借金の返済であって、消費ではないという扱いです）。

賃貸で暮らしている方が「うちの家賃は7万円で平均の4倍だ」と考えても、比べる意味はありません。詳しくは[住居費の記事](/articles/jukyohi)で説明します。

### 3. 平均は「あるべき金額」ではない

平均より多い費目があっても、それが悪いわけではありません。趣味に使うお金が多くて満足しているなら、それは選択の結果です。見直しの対象にすべきなのは「払っていることに気づいていないもの」「金額の根拠を説明できないもの」です。

## 住んでいる街の平均と比べる

支出は地域によってかなり違います。消費支出がいちばん多いのは **さいたま市（357,858円）**、少ないのは **那覇市（256,308円）** で、その差は約10万円です。

気候によって光熱費が変わり、鉄道網の密度によって交通費が変わり、子育て世帯の多さによって教育費が変わります。全国平均より、住んでいる街の平均と比べたほうが実感に近くなります。
